# Password Analyzer — Analizador de contraseñas

## Descripción

Password Analyzer es una herramienta desarrollada en Python que permite evaluar la fortaleza de una contraseña mediante diferentes criterios básicos de seguridad.

El programa analiza la longitud, la variedad de caracteres y la presencia de patrones o contraseñas habituales. Finalmente, muestra una puntuación y recomendaciones para mejorarla.

## Características principales

- Evaluación de la longitud de la contraseña.
- Comprobación de letras mayúsculas y minúsculas.
- Detección de números y símbolos especiales.
- Identificación de contraseñas y patrones comunes.
- Clasificación del resultado en débil, media o fuerte.
- Puntuación de seguridad sobre 6.
- Entrada de contraseñas oculta mediante `getpass`.

## Tecnologías utilizadas

- Python 3
- Módulo `getpass`
- Módulo `string`

## Requisitos

- Python 3 instalado.
- No necesita instalar bibliotecas externas.

## Ejecución

Clona el repositorio:

```bash
git clone https://github.com/izabelaslamnea/password-analyzer.git
```

Entra en la carpeta y ejecuta:

```bash
python password_analyzer.py
```

## Objetivo del proyecto

Practicar programación en Python y aprender conceptos básicos de seguridad de contraseñas, evaluación de criterios y detección de patrones predecibles.

## Consideraciones de seguridad

Este proyecto tiene fines educativos. Su puntuación se basa en reglas sencillas y no garantiza que una contraseña sea segura. No se deben introducir contraseñas reales ni reutilizadas.
